# `ado-pr` Skill Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the `ado-pr` Claude Code skill — the only mechanism by which Ralph (unattended) and Ralph's PR-feedback workflow talk to Azure DevOps pull requests. The skill exposes exactly five operations, one Python script per operation, all calling the ADO REST API through `scripts.ado_client` (Plan 2): `create-pr` (open a PR from a pushed feature branch to `main`, returning the PR ID), `read-threads` (dump every PR review thread + its comments + status as JSON), `reply` (post a single reply to a named thread), `set-status` (set a thread's status to one of `active`, `pending`, `fixed`, `closed`), and `show` (a summary of PR state, CI/build status, and reviewer decisions). The skill rejects `wontFix` and `byDesign` in `set-status` with a clear error explaining humans set those.

**Architecture:** A Claude Code skill at `skills/ado-pr/` containing one `SKILL.md` (frontmatter + body), five Python entry scripts under `skills/ado-pr/scripts/` (`create_pr.py`, `read_threads.py`, `reply.py`, `set_status.py`, `show.py`), and a shared `_common.py` that builds the `AdoClient` from `ADO_PAT` / `ADO_ORG_URL` / `ADO_PROJECT` env vars, validates the repository argument, and exposes the small helpers reused across operations. Every script follows the orchestrator's skill conventions: argparse, JSON-on-stdout, progress-on-stderr, exit 0 on success, exit 2 on validation / IO error, exit 3 on ADO-error (so callers can distinguish "bad input" from "ADO said no"). All ADO interaction is routed through `scripts.ado_client.AdoClient`; nothing in `skills/ado-pr/` opens a `requests.Session` of its own. Tests use the `responses` library (already added in Plan 2) to mock every ADO endpoint; no network access in CI.

**Tech Stack:** Python 3.12+, `uv`, `requests` (via `scripts.ado_client`), `responses` (tests), pytest, ruff, mypy strict, Azure DevOps REST API 7.1.

  # ado-pr

  ## What this skill does

  The `ado-pr` skill is Ralph's only handle on an Azure DevOps pull request.
  It contains five Python entry scripts under `skills/ado-pr/scripts/`, one
  per operation. Each script uses argparse, prints a JSON summary to stdout
  on success, sends progress to stderr, and uses the shared
  `scripts.ado_client.AdoClient` (Plan 2) for HTTP. Tests live at
  `tests/skills/test_ado_pr.py`.

  ## When to use it

  Use `ado-pr` whenever Ralph needs to talk to an ADO pull request. The
  executor's loop driver invokes it after pushing a feature branch
  (`create-pr`), the sweep invokes it to read PR state (`show`,
  `read-threads`), and Ralph's PR-feedback work item invokes
  `reply` + `set-status` for each addressed reviewer comment.

  ## Operations

  ### `create-pr` — open a PR from a feature branch to `main`

  ```bash
  uv run python skills/ado-pr/scripts/create_pr.py \
      --repo service-auth \
      --source-branch ralph/WI-1234 \
      --target-branch main \
      --title "WI-1234: add /healthz endpoint" \
      --body "Closes #1234. Implementation follows PLAN.md."
  ```

  | Flag | Required | Description |
  |---|---|---|
  | `--repo <name>` | yes | ADO Git repository name (not the project). |
  | `--source-branch <branch>` | yes | The feature branch that's already been pushed. Bare name; `refs/heads/` is added by the script. |
  | `--target-branch <branch>` | no (default `main`) | The branch the PR targets. |
  | `--title <text>` | yes | PR title. |
  | `--body <text>` | no | PR description in markdown. |
  | `--work-item <id>` | no, repeatable | Link the PR to one or more ADO work items by id (bare integer or `WI-<n>`). |
  | `--draft` | no | Open the PR in draft state. |
  | `--dry-run` | no | Compute the payload but do not POST. |

  Returns a JSON object with `pr_id`, `repo`, `source_branch`,
  `target_branch`, `url`, and `is_draft`. Exit codes: `0` success, `2`
  validation / IO error, `3` ADO returned non-2xx.

  REST endpoint: `POST {org}/{project}/_apis/git/repositories/{repo}/pullrequests?api-version=7.1`.

  ### `read-threads` — dump every thread + comments + status for a PR

  ```bash
  uv run python skills/ado-pr/scripts/read_threads.py \
      --repo service-auth \
      --pr-id 4242
  ```

  | Flag | Required | Description |
  |---|---|---|
  | `--repo <name>` | yes | ADO Git repository name. |
  | `--pr-id <int>` | yes | The pull request id returned by `create-pr` (or visible in the ADO UI URL). |
  | `--include-deleted` | no | Include comments marked deleted by ADO. Off by default. |

  Returns a JSON object with a `pr_id`, `repo`, and a `threads` array. Each
  thread is `{id, status, is_deleted, context, comments: [{id, author,
  content, published_date, comment_type}]}`. Exit codes: `0` success, `2`
  validation / IO error, `3` ADO returned non-2xx (incl. 404 for a missing
  PR).

  REST endpoint: `GET {org}/{project}/_apis/git/repositories/{repo}/pullRequests/{prId}/threads?api-version=7.1`.

  ### `reply` — post a reply comment to a named thread

  ```bash
  uv run python skills/ado-pr/scripts/reply.py \
      --repo service-auth \
      --pr-id 4242 \
      --thread-id 17 \
      --text "Applied; see commit abcdef0 — moved the validation into the dispatcher."
  ```

  | Flag | Required | Description |
  |---|---|---|
  | `--repo <name>` | yes | ADO Git repository name. |
  | `--pr-id <int>` | yes | Pull request id. |
  | `--thread-id <int>` | yes | Thread id, as returned by `read-threads`. Must be a positive integer. |
  | `--text <text>` | yes | The reply body in markdown. |

  Returns a JSON object with `comment_id`, `thread_id`, `pr_id`, `repo`,
  `posted_at`. Exit codes: `0` success, `2` validation / IO error, `3` ADO
  returned non-2xx.

  REST endpoint: `POST {org}/{project}/_apis/git/repositories/{repo}/pullRequests/{prId}/threads/{threadId}/comments?api-version=7.1`.

  ### `set-status` — set a thread's status

  ```bash
  uv run python skills/ado-pr/scripts/set_status.py \
      --repo service-auth \
      --pr-id 4242 \
      --thread-id 17 \
      --status fixed
  ```

  | Flag | Required | Description |
  |---|---|---|
  | `--repo <name>` | yes | ADO Git repository name. |
  | `--pr-id <int>` | yes | Pull request id. |
  | `--thread-id <int>` | yes | Thread id. |
  | `--status <enum>` | yes | One of `active`, `pending`, `fixed`, `closed`. **`wontFix` and `byDesign` are human-only and rejected with exit code 2 and an explicit error message.** |

  Returns a JSON object with `pr_id`, `repo`, `thread_id`, `status`,
  `previous_status`. Exit codes: `0` success, `2` validation error
  (including the `wontFix` / `byDesign` rejection), `3` ADO returned
  non-2xx.

  REST endpoint: `PATCH {org}/{project}/_apis/git/repositories/{repo}/pullRequests/{prId}/threads/{threadId}?api-version=7.1`.

  ### `show` — current PR state, CI results, reviewer decisions

  ```bash
  uv run python skills/ado-pr/scripts/show.py \
      --repo service-auth \
      --pr-id 4242
  ```

  | Flag | Required | Description |
  |---|---|---|
  | `--repo <name>` | yes | ADO Git repository name. |
  | `--pr-id <int>` | yes | Pull request id. |

  Returns a JSON object with `pr_id`, `repo`, `title`, `status` (one of
  `active`, `completed`, `abandoned`), `merge_status`, `source_branch`,
  `target_branch`, `is_draft`, `created_by`, `creation_date`,
  `closed_date`, `url`, plus arrays `reviewers` (each `{display_name,
  unique_name, vote, vote_label, is_required}`) and `statuses` (build /
  status check results: each `{context, state, description, target_url}`).
  Exit codes: `0` success, `2` validation / IO error, `3` ADO returned
  non-2xx.

  REST endpoints used:
  - `GET {org}/{project}/_apis/git/repositories/{repo}/pullRequests/{prId}?api-version=7.1`
  - `GET {org}/{project}/_apis/git/repositories/{repo}/pullRequests/{prId}/statuses?api-version=7.1`

  ## Environment variables

  | Variable | Purpose |
  |---|---|
  | `ADO_PAT` | Personal Access Token. Required scopes: `Code (Read & Write)` and `Pull Request Threads (Read & Write)`. |
  | `ADO_ORG_URL` | Organisation URL, e.g. `https://dev.azure.com/example-org`. |
  | `ADO_PROJECT` | ADO project name (NOT the repository name). |

  Every script reads these from the environment and exits with code 2 and
  a message naming the missing variable when any are absent.

  ## Exit codes (every operation)

  | Code | Meaning |
  |---|---|
  | 0 | Success. JSON summary on stdout. |
  | 2 | Validation / IO error before any HTTP call (bad CLI arg, missing env var, malformed id, human-only status). Message on stderr. |
  | 3 | ADO REST returned non-2xx (incl. missing PR, missing thread, auth failure). The `AdoError` message is forwarded to stderr. |

  ## Thread status semantics

  | ADO status | Set by `set-status` | Notes |
  |---|---|---|
  | `active` | yes | Ralph rarely sets this directly; ADO creates threads as `active` by default. |
  | `pending` | yes | Reserved for "comment-in-progress" cases; rare in Ralph's path. |
  | `fixed` | yes | Ralph sets after applying a fix. |
  | `closed` | yes | Ralph sets after a reviewer accepts a challenge. |
  | `wontFix` | NO — `set-status` rejects | Human-only. The bot cannot decide a reviewer's concern is unworthy of fixing. |
  | `byDesign` | NO — `set-status` rejects | Human-only. The bot cannot assert a design decision a human made. |

  ## What this skill does NOT do

  - It does NOT clone, fetch, or push git refs. The caller is responsible
    for pushing the feature branch before invoking `create-pr`.
  - It does NOT set `wontFix` or `byDesign` thread statuses — those are
    decisions only a human reviewer can make.
  - It does NOT modify the PR title or body after creation. Updates to a
    PR happen by pushing more commits to the feature branch.
  - It does NOT manage branch policies; that is `scripts/setup_ralph_queue.py`'s
    job (Plan 2).
  - It does NOT open an MCP server; Ralph invokes the skill via the
    Claude Code `Skill` tool, which spawns the Python scripts directly.

  ```python
  """Shared helpers for the ``ado-pr`` skill's five entry scripts.

  - ``load_client(repo)`` reads ``ADO_PAT``, ``ADO_ORG_URL``, ``ADO_PROJECT``
    from the environment, validates the repo argument, and returns the
    ``AdoClient`` plus the trimmed repo name.
  - ``parse_pr_id`` / ``parse_thread_id`` accept bare positive integers and
    raise ``FatalError`` for anything else.
  - ``FatalError`` is the in-process signal for "validation / IO error" —
    the wrapping ``main`` of each entry script catches it and returns 2.
  - ``ALLOWED_STATUSES`` / ``HUMAN_ONLY_STATUSES`` are referenced by
    ``set_status.py`` so the enum lives in exactly one place.
  - ``handle_ado_error`` is the standard exit-3 path: print the
    ``AdoError`` to stderr and return ``3``.
  """
  from __future__ import annotations

  import os
  import sys
  from pathlib import Path

  # Make ``scripts.ado_client`` importable when this script is invoked
  # directly with ``uv run python skills/ado-pr/scripts/<op>.py``.
  _REPO_ROOT = Path(__file__).resolve().parents[3]
  if str(_REPO_ROOT) not in sys.path:
      sys.path.insert(0, str(_REPO_ROOT))

  from scripts.ado_client import AdoClient, AdoError  # noqa: E402


  # Thread statuses that ``set-status`` will accept from Ralph.
  ALLOWED_STATUSES: tuple[str, ...] = ("active", "pending", "fixed", "closed")

  # Thread statuses ``set-status`` REJECTS. Setting these is a judgement only
  # a human reviewer can make: ``wontFix`` says a concern isn't worth fixing,
  # ``byDesign`` asserts an existing design decision. The bot cannot make
  # either of those calls.
  HUMAN_ONLY_STATUSES: tuple[str, ...] = ("wontFix", "byDesign")


  class FatalError(RuntimeError):
      """Raised on validation / IO failure. Mapped to exit code 2 by callers."""


  def fail(message: str) -> int:
      """Print ``message`` to stderr and return exit code 2."""
      print(f"error: {message}", file=sys.stderr)
      return 2


  def handle_ado_error(error: AdoError) -> int:
      """Print an :class:`AdoError` to stderr and return exit code 3."""
      print(f"ado error: {error}", file=sys.stderr)
      return 3


  def _require_env(name: str) -> str:
      value = os.environ.get(name, "").strip()
      if not value:
          raise FatalError(f"environment variable {name} is required")
      return value


  def load_client(repo: str) -> tuple[AdoClient, str]:
      """Build the ADO client + return the validated repo name.

      Raises :class:`FatalError` if any of ``ADO_PAT`` / ``ADO_ORG_URL`` /
      ``ADO_PROJECT`` is missing, or if ``repo`` is empty.
      """
      if not isinstance(repo, str) or not repo.strip():
          raise FatalError("--repo must be a non-empty repository name")
      pat = _require_env("ADO_PAT")
      org_url = _require_env("ADO_ORG_URL")
      project = _require_env("ADO_PROJECT")
      client = AdoClient(org_url=org_url, project=project, pat=pat)
      return client, repo.strip()


  def parse_pr_id(raw: str) -> int:
      """Parse ``--pr-id`` argv. Bare positive integer only."""
      return _parse_positive_int(raw, label="pr id")


  def parse_thread_id(raw: str) -> int:
      """Parse ``--thread-id`` argv. Bare positive integer only."""
      return _parse_positive_int(raw, label="thread id")


  def _parse_positive_int(raw: str, label: str) -> int:
      raw = (raw or "").strip()
      if not raw.lstrip("-").isdigit():
          raise FatalError(f"{label} {raw!r} must be a positive integer")
      try:
          value = int(raw)
      except ValueError as exc:
          raise FatalError(
              f"{label} {raw!r} must be a positive integer"
          ) from exc
      if value <= 0:
          raise FatalError(f"{label} {raw!r} must be a positive integer")
      return value


  def parse_branch(raw: str) -> str:
      """Normalise a branch argument.

      Strip a leading ``refs/heads/`` if present and surrounding whitespace.
      The script later re-prepends ``refs/heads/`` when building the REST
      payload, so the canonical in-process form is the bare branch name.
      """
      stripped = (raw or "").strip()
  ```

  ```python
      source_branch: str,

          if isinstance(href, str) and href:
  ```

  ```python
  Rationale for the rejection:
  - ``wontFix`` says a concern is not worth fixing — a value judgement only
    a human reviewer can make.
  - ``byDesign`` asserts an existing design decision the bot cannot
    independently verify.

  Stdout JSON: { "pr_id", "repo", "thread_id", "status", "previous_status" }.
  Exit codes: 0 success, 2 validation (including the human-only rejection),
  3 ADO error.

  import json
  import sys
  from pathlib import Path
  from typing import Any

  if str(_HERE) not in sys.path:

      ALLOWED_STATUSES,

      handle_ado_error,

      parse_pr_id,

  )

  # die at argparse parse time (exit 2 from argparse itself) and human-only
  # statuses fall through to the rejection check below — which prints a
  # tailored error message naming the rejected status.

              + ". Rejected (human-only): "
              + ", ".join(HUMAN_ONLY_STATUSES)
              + "."
          ),

              (

                  f"/threads/{thread_id}"
              ),
              json_body={"status": args.status},
          )

          if not isinstance(response, dict):
              raise FatalError(

              "previous_status": previous_status,
  ```

## Task 8 — Implement `show.py`

**Files**
- Create: `skills/ado-pr/scripts/show.py`

**Steps**

- [ ] 1. Write `skills/ado-pr/scripts/show.py` with the exact content below. ADO encodes reviewer votes as small signed integers; the script translates the well-known values to human-readable labels (`approved`, `approved-with-suggestions`, `no-vote`, `waiting`, `rejected`) per the documented enum:
  ```python
  """``ado-pr show`` — PR state, CI/status checks, reviewer decisions.

  REST endpoints:
      GET {org}/{project}/_apis/git/repositories/{repo}/pullRequests/
          {prId}?api-version=7.1
      docs: https://learn.microsoft.com/en-us/rest/api/azure/devops/git/pull-requests/get-pull-request

      GET {org}/{project}/_apis/git/repositories/{repo}/pullRequests/
          {prId}/statuses?api-version=7.1
      docs: https://learn.microsoft.com/en-us/rest/api/azure/devops/git/pull-request-statuses/list

  ADO reviewer vote integers (Microsoft.TeamFoundation.SourceControl.WebApi):
      10  approved
       5  approved with suggestions
       0  no vote
      -5  waiting for author
     -10  rejected

  Stdout JSON includes pr_id, repo, title, status (active/completed/abandoned),
  merge_status, source_branch, target_branch, is_draft, created_by,
  creation_date, closed_date, url, reviewers (list), statuses (list).

  Exit codes: 0 success, 2 validation, 3 ADO error.
  """
  from __future__ import annotations

  import argparse
  import json
  import sys
  from pathlib import Path
  from typing import Any

  _HERE = Path(__file__).resolve().parent
  if str(_HERE) not in sys.path:
      sys.path.insert(0, str(_HERE))

  from _common import (  # noqa: E402
      AdoError,
      FatalError,
      fail,
      handle_ado_error,
      load_client,
      parse_pr_id,
  )


  VOTE_LABELS: dict[int, str] = {
      10: "approved",
      5: "approved-with-suggestions",
      0: "no-vote",
      -5: "waiting",
      -10: "rejected",
  }


  def _strip_refs_prefix(ref: str) -> str:
      prefix = "refs/heads/"
      return ref[len(prefix):] if ref.startswith(prefix) else ref


  def _project_user(raw: Any) -> dict[str, Any] | None:
      if not isinstance(raw, dict):
          return None
      return {
          "display_name": str(raw.get("displayName") or ""),
          "unique_name": str(raw.get("uniqueName") or ""),
      }


  def _project_reviewer(raw: dict[str, Any]) -> dict[str, Any]:
      vote_raw = raw.get("vote")
      vote = int(vote_raw) if isinstance(vote_raw, int) else 0
      return {
          "display_name": str(raw.get("displayName") or ""),
          "unique_name": str(raw.get("uniqueName") or ""),
          "vote": vote,
          "vote_label": VOTE_LABELS.get(vote, "unknown"),
          "is_required": bool(raw.get("isRequired", False)),
      }


  def _project_status(raw: dict[str, Any]) -> dict[str, Any]:
      context = raw.get("context") or {}
      name = ""
      genre = ""
      if isinstance(context, dict):
          name = str(context.get("name") or "")
          genre = str(context.get("genre") or "")
      return {
          "name": name,
          "genre": genre,
          "state": str(raw.get("state") or ""),
          "description": (
              str(raw.get("description"))
              if raw.get("description") is not None
              else None
          ),
          "target_url": (
              str(raw.get("targetUrl"))
              if raw.get("targetUrl") is not None
              else None
          ),
      }


  def _extract_url(response: dict[str, Any]) -> str:
      links = response.get("_links") or {}
      web = links.get("web") if isinstance(links, dict) else None
      if isinstance(web, dict):
          href = web.get("href")
          if isinstance(href, str) and href:
              return href
      url = response.get("url")
      return str(url) if isinstance(url, str) else ""


  def _parse_args(argv: list[str]) -> argparse.Namespace:
      parser = argparse.ArgumentParser(
          prog="ado-pr show",
          description=(
              "Print a JSON summary of a pull request: state, CI/status "
              "checks, reviewer decisions. Reads ADO_PAT, ADO_ORG_URL, "
              "ADO_PROJECT from the environment."
          ),
      )
      parser.add_argument("--repo", required=True, help="ADO Git repository name.")
      parser.add_argument("--pr-id", required=True, help="Pull request id.")
      return parser.parse_args(argv)


  def main(argv: list[str] | None = None) -> int:
      args = _parse_args(argv if argv is not None else sys.argv[1:])
      try:
          pr_id = parse_pr_id(args.pr_id)
          client, repo = load_client(args.repo)

          print(
              f"reading PR {pr_id} state in {repo}...",
              file=sys.stderr,
          )
          pr = client.get(
              f"git/repositories/{repo}/pullRequests/{pr_id}",
          )
          if not isinstance(pr, dict):
              raise FatalError(
                  "PR response was not a JSON object: " + repr(pr)[:200]
              )

          print(
              f"reading PR {pr_id} status checks in {repo}...",
              file=sys.stderr,
          )
          statuses_response = client.get(
              f"git/repositories/{repo}/pullRequests/{pr_id}/statuses",
          )
          raw_statuses = (
              statuses_response.get("value", [])
              if isinstance(statuses_response, dict)
              else []
          )

          reviewers_raw = pr.get("reviewers") or []
          reviewers = [
              _project_reviewer(r) for r in reviewers_raw if isinstance(r, dict)
          ]
          statuses = [
              _project_status(s) for s in raw_statuses if isinstance(s, dict)
          ]

          summary: dict[str, Any] = {
              "pr_id": pr_id,
              "repo": repo,
              "title": str(pr.get("title") or ""),
              "status": str(pr.get("status") or ""),
              "merge_status": (
                  str(pr.get("mergeStatus"))
                  if pr.get("mergeStatus") is not None
                  else None
              ),
              "source_branch": _strip_refs_prefix(str(pr.get("sourceRefName") or "")),
              "target_branch": _strip_refs_prefix(str(pr.get("targetRefName") or "")),
              "is_draft": bool(pr.get("isDraft", False)),
              "created_by": _project_user(pr.get("createdBy")),
              "creation_date": (
                  str(pr.get("creationDate"))
                  if pr.get("creationDate") is not None
                  else None
              ),
              "closed_date": (
                  str(pr.get("closedDate"))
                  if pr.get("closedDate") is not None
                  else None
              ),
              "url": _extract_url(pr),
              "reviewers": reviewers,
              "statuses": statuses,
          }
          print(json.dumps(summary, indent=2, sort_keys=True))
          return 0

      except FatalError as exc:
          return fail(str(exc))
      except AdoError as exc:
          return handle_ado_error(exc)


  if __name__ == "__main__":
      raise SystemExit(main())
  ```
